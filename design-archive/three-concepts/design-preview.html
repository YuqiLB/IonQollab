BEHIND THE SCENE

An envelope, not a promise.

The invitation is encrypted locally by Qrush’s existing toy RSA code: p = 3, q = 5, n = 15, e = d = 3. These tiny, unpadded keys offer no security.

The interception is scripted. Zeno copies the packet; this preview does not run a quantum job or decrypt it. The moving envelope is a visual metaphor, not a trace of network traffic. Nothing is sent to a server.

Qrush is set in a fictional future. This scene does not demonstrate present-day quantum hardware breaking deployed messaging encryption.
